# Current teaching metadata

`lesson_plan.json` is the published 86-slide, 45-step lesson snapshot; `final_slide_content.json` contains the full slide text and notes; `SLIDE_DEMO_MAP.md` supplies clickable current demo references; `references.json` retains numbered citations; `measurement_lessons.json` contains the worked operands and known-answer checks.

Original source-edition identifiers and workspace-relative paths are retained as provenance, including paths to older decks that are intentionally not bundled. Current repository entry points are resolved by [repository_paths.json](repository_paths.json). Functional presentation/demo hyperlinks already use the sibling directories and are verified against this tree.
