# CPU experiment sources and evidence

The internal `scripts/`, `data/`, `results/`, `figures/`, `beginner/`, `research/` and `chronological/` relationships are retained from the executed numerical workspace. This allows the six included scripts to run without machine-specific absolute paths. See [experiment commands and interpretation](../docs/EXPERIMENTS.md).

Inputs include public images and labeled synthetic conditions. Preserve [provenance](data/PROVENANCE.md), the [ITK license](data/ITK_LICENSE.txt), seeds and recorded library versions. Historical source-slide labels in some results are provenance; the current [slide/demo map](../content/SLIDE_DEMO_MAP.md) controls the published lesson.
